bcrypt - modulo do python para criptografar senhas ou outros dados



Metodos HTTP - Crud

GET	-	Read		-	Buscar ou listar dados
POST	-	Create		-	Criar novo recurso (é preciso dados passado pelo usuario)
PUT	-	Update(completo)-	Substituir completamente um recurso especifico
PATCH	-	Update(parcial)	-	Atualizar apenas compos especificos de um recurso
DELETE	-	Delete		-	Remover um recurso do servidor

Base da API REST
